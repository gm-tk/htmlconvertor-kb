102. **(Universal)** **An `infoTrigger`'s hover text — its `info="…"` value — is cased and stopped by its length.** **One word** → a capital first letter and **no** full stop (`info="Dog"`, never `dog` / `Dog.`; a hyphenated word is one word). **More than one word** → a capital first letter **and** a closing full stop (`info="Parts of the body."`, never `parts of the body`). It applies to every element carrying the `infoTrigger` class — the inline `<span class="infoTrigger">`, the `<p class="infoTrigger">` hotspots of an `infoImage`, and the `<div class="label infoTrigger">` labels of an `imageLabel` diagram. Only the first letter is raised (macrons kept: `ā` → `Ā`) and the rest keeps the writer's casing; a value already ending in `?` or `!` keeps that mark; a trailing comma, colon or semicolon gives way to the full stop; a value opening with a digit or symbol is not re-cased. Only the `info` value changes — never the visible trigger word. The human-built pages do not always follow this (they are corrected in review); the rule outranks them. Source: Sam Sharpe, 25 November 2026 (the correction recurs in Simon's edits), with his two examples. Full rule: `04_COMP_SEGMENTS_OVERLAYS.md` → Info Trigger (`04B`) (CL-0159)

103. **(Cohort — Maths modules)** **The Maths templates' shapes and angles library is built from, never re-sourced — and its iStock sets are always acknowledged as *Adapted*.** The Refresh Template's `Module assets/Maths/Math templates/guidelines/Math assets/` holds 2D coloured shapes (SVG), 2D shapes with arrows (SVG, one per phase 1–4), 3D shapes (PNG — coloured, `outline`, some `grey`) and angles (SVG, **Phase 3 only**). A Maths image request naming a library item builds `<img class="img-fluid" loading="lazy" src="images/<library file name>" alt="<shape name>">` — the file name verbatim, its misspellings never corrected — plus one `Designer/Developer To Do:` to copy the file into the module's `images/` folder from its library folder (a 2D SVG's colour can be changed there; a 3D PNG's cannot). Shapes with arrows take the module's phase; an angle outside Phase 3 adds a To Do to adapt the Phase 3 file and save the copy back to the library. Each lesson using a 2D set carries `Illustrations: Basic shapes geometric form collection … , iStock 1388076960, Getty Images. Adapted. Used with permission.`, each using the 3D set `Illustrations: Realistic 3d geometric shapes. … , iStock 1251354077, Getty Images. Adapted. Used with permission.` — the sets' own lines verbatim with `Adapted.` added; the angles carry none. Source: Eliza Rogers, 25 November 2026. Full rule and file list: `14_SUBJECT_GLOBAL_PARAMETERS.md` → §14.14 (`14E`) (CL-0160)

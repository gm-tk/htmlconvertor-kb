## 14.11 Cross-cutting notes

- **"Upload to Dropbox" series label (BLL / LS / HPE / Social Sciences).** These four families label the dropbox submission button **"Upload to Dropbox"** (also seen as *Upload to dropbox*). This is a **series-scoped label** that sits **alongside** — and does **not** overturn — the universal **"Go to dropbox" / "Go to portfolio"** default (constraint 55 / `05` → Buttons). For any module outside these four families, the universal "Go to …" label still applies. (The HPE celebration page also carries the `goJournal` **"Go to your journal"** heading next to its "Upload to dropbox" button — constraint 96.)
- **Central `imageCentral` assets recur across families.** Languages (per-language `… assets/` folders — §14.1), Taonga (`tui_characters/` — §14.3), HPE (`health & PE characters/` + the celebration `.gif` — §14.8), BLLR (`bookworms/` — §14.9), MiW (`kea_characters/` + the NZ map — §14.10), Technology (`Technology/strand/` + the shared `congradulations/` celebration gif — §14.12), Science (`Science Characters/` — §14.13), Maths (`Maths Characters/` — §14.14) and Social Sciences (the shared `congradulations/` celebration gif — §14.17) all use centralised template assets carrying `class="img-fluid imageCentral"`. **Every one of them — and the default avatars (`Character_assets/`), the dispositions (`beA-NCEA/` and the Phase 1–4 `beAKiwi` div), the Technology TENZ / character / hat images (`technology/`), the weather icons (`weatherIcons/`) and the AI guidelines icons (`AI guidelines icons/`) — now has its own writer tag, `[Centralised image: <image name>]`, listed with its exact path in the central-images registry, §14.16 (`14F`; constraint 99; CL-0141).** These are design-team central-store assets — the `imageCentral` reservation in `01` (never on writer-specified images) is unchanged.
- **BLL dropbox-wrapper carve-out.** BLL is the **one** series that does **not** append the `dropbox` modifier to the `.activity` wrapper (§14.7). This carve-out is **scoped to BLL only** — it does **not** extend to the separate **BLLR** series (§14.9). Every other series follows constraint 43 unchanged.
- **`stickyNav` in the `<head>`.** The sticky-nav script recurs across Languages Phase 1–4 (every page), CED Phase 5 (dictionary links), HPE (Fundamentals + The Hub — CL-0146), Technology (Technology fundamentals, Glossary, Help — CL-0148) and Maths (Fundamentals + The Hub — CL-0154), and in any module whose writer asks for a floating-nav glossary (every page — `05` → Glossary, CL-0122). Each is documented in its section above. (Split Mode base files are the exception — they carry **no** `stickyNav`; see `13_SPLIT_MODE.md`.)
- **Deferred-item convention.** Every "TO DO / TBC / placeholder / under development" item across these families is emitted as a **visible `Designer/Developer To Do:` red-note placeholder** (red + bold), never a hidden comment and never silently dropped — the pattern is built and the pending asset/URL/setup is flagged for production. See `02_DATA_CONTENT_VERIFICATION.md` → Source-Specific Red-Note Prefixes; `00` constraint 59.

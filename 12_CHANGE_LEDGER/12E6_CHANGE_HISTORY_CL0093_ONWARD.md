| CL-0093 | Sunday, 13th September, 2026 | **NEW constraint 92 — the language-font classes `jp-text`, `ch-text` and `pinyin` are MANDATORY on every occurrence, and the conversion applies them.** The KB carried the three class names in a five-row table (`05A` → Language Fonts) and **no rule at all** about applying them, so Japanese, Chinese and pinyin text was emitted unclassed and rendered in the wrong typeface. **THE RULE:** Japanese (hiragana, katakana, kanji) carries `jp-text`; Chinese (Han characters, simplified or traditional) carries `ch-text`; pinyin — the romanised sounding-out of Chinese, with or without tone marks — carries `pinyin`. **Every run, in every context** — `<h2>`–`<h5>`, `<p>`, bold/italic runs, `<li>`, `<th>`, `<td>`, and nested inside the `<h1><span>` header title — not only the first occurrence and not only the vocabulary tables. **The whole run is wrapped, internal punctuation included** (`他(她)是我的(哥哥/弟弟/姐姐/妹妹`, `Tā jīntiān bā suì.`), surrounding English left outside. **Four equivalent carriers**, all four evidenced in the supplied reference page: a `<span>` around the run, or the class directly on an inline element containing only that run — `<b class="ch-text">`, `<span class="ch-text"><b>`, `<b><span class="ch-text">`. A colour class joins in the same attribute (`class="jp-text green-text"`) and never replaces the language class. **THE MACRON BOUNDARY — the question the instruction itself raised** (*"unless you have some way to differentiate Japanese and Chinese from nz letters"*): **te reo Māori and English are NEVER wrapped.** `ā ē ī ō ū Ā Ē Ī Ō Ū` are ordinary New Zealand letters — `Māori`, `Manawatū`, `ākonga` take no class — and **a macron alone never identifies pinyin**, because it is shared with pinyin's first tone. | CL-0095 | Sunday, 13th September, 2026 | **Constraint 1 EXTENDED — a leading LABEL PREFIX is stripped from a body heading, universally.** `WJFUN112` carried `🔴[RED TEXT] [H1] [/RED TEXT]🔴FUNdamental: Audience and Purpose` in the introduction while the `[H1 TITLE BAR]` read `Audience and Purpose | Te Whakaminenga me te Whāinga`.
